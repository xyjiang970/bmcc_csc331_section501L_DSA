📝 How to Use

This is your original C++ program running in the browser! Type expressions in the terminal below.

Supported Operators: + - * / % ^

Examples to try:

  • 23+ → evaluates to 5 (2 + 3)
  • 34*5+ → evaluates to 17 ((3 * 4) + 5)
  • 95- → evaluates to 4 (9 - 5)
  • 23^ → evaluates to 8 (2³)
  • 84/2- → evaluates to 2 ((8 / 4) - 2)
💡 Tips:
  • Click in the terminal below to start typing
  • Press Enter after each expression
  • Type end-of-file to exit/restart the program
  • To stop the program, press Ctrl+C (or Cmd+C on Mac)
