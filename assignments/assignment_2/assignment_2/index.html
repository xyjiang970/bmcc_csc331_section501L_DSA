📚 Book Management System

About This Program

Course: CSC331 - Data Structures & Algorithms | Section 501L

Assignment: Program 2: Linked List Implementation

Author: Jason Jiang

📖 How to Use

Enter transactions in the input box (one per line), then click "Process All".

Supported Transactions:

  • A [ID] [Title] - Add a new book
  • R [ID] - Remove a book
  • O [ID] [Quantity] - Order books (increase inventory)
  • S [ID] [Quantity] - Sell books (decrease inventory)
  • L - List all books
  • C - Clear the book list

Preset Examples:

  • A 10 book1 - Add book with ID 10
  • A 10 book2 - Try adding duplicate ID
  • A 20 book3 - Add book with ID 20
  • L - List all books
  • R 30 - Try removing non-existent book
  • R 10 - Remove book with ID 10
  • O 10 7 - Order books (tests non-existent book)
  • O 20 7 - Order 7 copies of book 20
  • L - List books again
