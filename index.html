Assignment 3: Stack Implementation

Due: October 31, 2025 | Status: ✅ Completed

An interactive postfix (Reverse Polish Notation) expression evaluator implemented in C++ and compiled to WebAssembly. This program uses a linked-list based stack data structure to parse and evaluate arithmetic expressions with full error handling.

Features:

  • Stack-based expression evaluation
  • Support for operators: +, -, *, /, %, ^
  • Division by zero detection
  • Integer validation for modulus operations
  • Runs natively in the browser (no installation required)
